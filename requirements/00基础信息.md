## 站点定位（差异化策略）

竞品 sephiria.net 已覆盖 beginner/builds/weapons/characters。本站差异化主打：
1. **secrets 深度**（constellations 星座隐藏房、Elru Quest、100%成就路线）——竞品只有摘要级内容
2. **co-op 排查**（联机失败/掉线/物品交易规则）——竞品覆盖最弱的板块
3. **版本时效性**（每篇标注 game version + last updated，对齐官方1.0.x补丁节奏）

## 内容事实库（写文章时引用）

- 6种基础武器：Sword and Shield / Greatsword / Dagger / Crossbow / Katana / Quarterstaff (Staff)
- 武器有变体进化路线（例：Flame Dagger → Blazing Blade / Burning Fang）
- 系统：talismans、artifacts、天赋点、puzzle-like 库存管理（相邻格子联动强化）
- 27套可玩服装（8默认 + 19解锁）
- Secret rooms：隐藏房墙壁可识别，内有奖励；constellations 以独立隐藏房形式存在
- Elru Quest：3处藏匿点（萝卜农场、服装店、方舟解谜房）
- Co-op：Steam联机、4人合作、物品可交易、可复活，有连接问题
- Builds 支持 Preset Codes（分享码导入）
- Hard Mode 至少到 Tier 35
- 社区标准数据源：Kean's Sephiria Compendium（Google Spreadsheet）
